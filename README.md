
# Road Lane Lines Detection

## Project Description
This project detects road lane lines using OpenCV
and Computer Vision techniques.

## Technologies Used
- Python
- OpenCV
- NumPy
- Matplotlib

## Techniques
- Grayscale Conversion
- Gaussian Blur
- Canny Edge Detection
- Region of Interest
- Hough Line Transform

## Output
Detected road lane lines are highlighted in green.
